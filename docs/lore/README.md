# Библия лора: гоголевская Полтавщина

Атмосферная детективная игра без боя и прокачки в мире «Вечеров на хуторе близ Диканьки» и «Миргорода».
Главный вопрос каждого дела — **«нечисть или люди?»**. Тон — как у Гоголя: смешно и жутко одновременно.
Визуальный ориентир — «Украинская ночь» Куинджи (1876).

## Рабочие решения (можно менять)

- **Время действия:** 1811 год — шестая ревизия («перепись душ»), Полтавская губерния с 1802 года, впереди 1812-й.
  Гоголю два года, он живёт в Васильевке.
- **Сезон:** «Ревизская сказка» — восемь дел по сёлам и городам Полтавщины, сквозная тайна «губернского стряпчего»
  и левого рукава красной свитки (см. `05-cases.md`).
- **Герой:** недоучившийся философ из киевской бурсы, однокашник Хомы Брута, ныне копиист казённой палаты,
  ездит сверять ревизские сказки. Его свеча — огарок из той самой церкви.
- **Первое дело:** «Утопленник» — Русальная неделя, село из «Майской ночи» десять лет спустя.

## Пометки в текстах

**[Н]** — наше изобретение · **[?]** — не проверено или источники расходятся.

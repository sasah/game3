# Библия проекта «Ревизская сказка»

Атмосферный детективный квест в мире Гоголя: Полтавщина, Диканька, Миргород, 1811 год.
Изометрия поверх живописи, расследования без боя и прокачки, серая мораль и вечный вопрос
**«нечисть или люди?»**. Играется в браузере телефона.

Пометка **«Зафиксировано\*»** значит: решение принято, но со звёздочкой — его можно пересмотреть,
если прототип покажет иное. **«Открыто»** — решение ещё не принято.

## Игра в одном абзаце

Весна 1811 года. Недоучившийся философ киевской бурсы, однокашник Хомы Брута, служит копиистом
Полтавской казённой палаты и ездит по сёлам сверять шестую ревизию — перепись «душ». В каждом селе
его ждёт дело: утопленник, пропавший мальчик, ночной караул, заколдованное место. Свидетели врут,
нечисть то ли есть, то ли нет, а то, что герой запишет в ревизскую сказку, решит чью-то судьбу:
вольный казак станет крепостным, беглый — мёртвым, живой — свободным. Правильного ответа нет.
Есть свеча, которая показывает скрытое, рассказчик Рудый Панько, который привирает,
и губернский стряпчий, который скупает подписи. Человек он или черт — решит игрок.

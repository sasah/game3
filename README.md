# game3 — «Ревизская сказка»

Атмосферная детективная игра в мире Гоголя: Полтавщина, Диканька, Миргород, 1811 год.
Без боя и прокачки — расследования, свидетели, свеча, в свете которой видно скрытое,
и вечный вопрос «нечисть или люди?».

- `docs/lore/` — библия лора (тексты Гоголя, история, фольклор, быт, черновики дел).
- `docs/research/` — исследования по движкам, доставке сборок на телефон и визуальным стилям.
- `prototypes/` — прототипы. Первый — тест атмосферы «Украинская ночь».
